# AI 热点口播视频 · Tech Explainer

**把你的 AI 热点口播，做成观众看得懂、画面有依据、风格统一的视频。**

为 AI 内容创作者准备的 Agent Skill。用于新产品走红、功能更新、模型与工具对比、Agent 趋势等热点口播视频。理解你的观点，设计分镜、匹配素材、制作解释页与策略页，再按确认过的风格完成剪辑。需要参考其他博主时，也可以拆解其结构、视觉与节奏，适配到你的内容。

保留你的出镜与原声，从口播到分镜、策略页、B-roll，再到上下分屏成片。

[功能介绍](#它能帮你做什么) · [快速开始](#快速开始) · [使用示例](#使用示例) · [工作方式](#工作方式) · [能力与依赖](#能力与依赖)

## 从“讲清楚”到“看明白”

一个 AI 产品突然走红，或一个新功能引发讨论。你录好了自己的解读，还要决定：怎样让观众看见它的能力？技术概念如何画清楚？和其他产品的区别怎样呈现？观众还没读完，画面是否就切走了？

这个 Skill 把这些决定组织成可复用的制作方法，让 Agent 根据口播的观点和逻辑设计画面，并在正式剪辑前交付可审核的静态分镜。

## 它能帮你做什么

| 功能 | 怎样帮助你 | 交付内容 |
| --- | --- | --- |
| 口播理解与分镜设计 | 提炼观点、依据和逻辑，为完整语义安排画面 | 口播与画面的映射、静态分镜 |
| 参考博主拆解与适配 | 学习参考片的结构、视觉和节奏，用于你的新口播 | 带时间码的拆解表、风格说明与适配方案 |
| 真实素材匹配 | 将产品能力与判断对应到真实界面、演示或操作结果 | 素材清单、来源和待补缺口 |
| 解释页与策略页制作 | 用对照、流程和关系图呈现概念、产品差异和作者判断 | 实际内容的页面样张 |
| 系列风格复用 | 沿用确认过的配色、布局和表达规则 | 风格一致的新页面与分镜 |
| 剪辑与验收 | 按语义切镜，检查阅读节奏、裁切、字幕与音画同步 | 代表性短样片、完整视频与检查结果 |

## 拆解参考博主，做成自己的视频

给 Agent 一条参考视频和你的新口播，它会先找到参考片中值得迁移的表达方法，再设计本片。

分析覆盖六个维度：内容结构、口播与画面配合、视觉系统、阅读与剪辑节奏、动态与声音、人物表达。

```text
使用 $edit-tech-explainer，拆解我上传的参考视频。
重点看：开头怎样吸引注意、哪句话触发画面变化、
复杂概念怎样呈现，以及每页为什么停留那么久。

给我带时间码的拆解表，再把这些方法适配到我的新口播。
保留我的出镜、观点和原声，先交付静态样张。
```

你会得到三份相互对应的结果：

1. **参考拆解表**：时间码、代表帧、观察和可迁移规则。
2. **风格说明**：配色、布局、字幕层级、转场与节奏。
3. **本片适配表**：参考规律、对应口播、新画面，以及调整理由。

只有截图时，分析范围限于静态视觉；完整节奏和声音需要实际视频。参考方法用在新内容中，换口播后重新测量切点。

## 快速开始

### 1. 准备 Skill

将完整的 `edit-tech-explainer` 文件夹放入支持 Agent Skills 的工具所使用的技能目录。保留 `SKILL.md`、`references/`、`assets/` 和 `agents/` 的相对位置。

也可以在能读取本地文件的 Agent 中，直接提供 `SKILL.md` 的实际路径，让它读取并执行。

> 从 [GitHub Skill 目录](https://github.com/huaxialucaicaizi/awesome-ai-marketing-growth/tree/main/skills/edit-tech-explainer) 获取完整文件夹。Skill 定义制作方法；转写、检索、设计与视频合成使用你的 Agent 环境中实际可用的工具。

### 2. 给它素材和交付要求

提供自己的 AI 热点口播视频；已有脚本或字幕时一并提供。说明目标观众、希望采用的风格，以及这一轮需要分镜、样片还是全片。想借鉴其他博主时，再补充参考视频和希望借鉴的部分。

第一次使用，可以复制这段提示词：

```text
使用 $edit-tech-explainer 处理我上传的 AI 热点口播。

观众：AI 小白。
风格：浅色蓝紫科技风，9:16，上方 B-roll、下方原口播。

先理解每段的观点和逻辑，再匹配画面。
本轮交付：一张代表性策略页 + 静态分镜预览。
每个分镜附对应口播、素材来源和预计停留时间。
确认后再开始剪辑。
```

若你的工具不支持 `$` 调用，改为要求它读取 `edit-tech-explainer/SKILL.md`，其余要求可以沿用。

## 使用示例

### 产品走红：它是什么，为什么值得关注？

```text
使用 $edit-tech-explainer 处理这条“一个 AI Agent 产品为什么
突然走红”的口播。根据我的脚本解释它是什么、能做什么、
适合谁。介绍能力时用真实产品界面或演示，解释原理和
我的判断时用浅色科技风图示。
先给我一张代表页和静态分镜，缺少证据的地方标出来。
```

**预期交付：** 产品素材与来源、口播映射、解释页样张，以及保留原出镜的分屏预览。

### 功能更新：这次变化对普通用户有什么用？

```text
使用 $edit-tech-explainer 处理这条 AI 工具新功能解读。
按我的口播展示功能变化、实际任务和使用结果。
有真实测试就用测试素材；没有验证的效果标为待核对。
先做一组静态分镜，帮助 AI 小白理解这个更新能解决什么问题。
```

**预期交付：** 功能与场景的对应画面、真实操作页、待补素材清单。

### 产品对比：看起来都能做，差别在哪里？

```text
使用 $edit-tech-explainer，把我对两个 AI 工具的比较口播
设计成视频。根据脚本选取一致的比较维度，用真实界面
展示操作差异，用对照页解释适用场景和我的判断。
先交付一张对比页，保留脚本里的条件和限制。
```

**预期交付：** 对齐比较维度的页面样张、对应操作画面与语义切点。

### 系列内容：沿用确认过的视觉语言

```text
使用 $edit-tech-explainer，沿用我提供的系列参考片风格。
保留原 A-roll 和原声。根据这次口播重新安排素材与切点，
先做目录页、一个策略页和一个真实操作页供我确认。
```

**预期交付：** 同一视觉体系下的三个代表页面及对应口播，便于在扩展全片前确认。

## 默认视觉

白色或浅灰底、淡蓝紫渐变、深色标题与蓝紫重点。通过立体模块、柔和光影和清晰的空间关系呈现科技感。

默认采用 **9:16 上下分屏**，上方展示 B-roll，下方保留原口播人物。每页围绕一个观点组织，按完整语义切镜，并给观众足够的阅读时间。

产品能力与功能讲解使用真实界面、演示或操作结果；概念、差异和作者分析使用自制解释页或策略页。画面根据热点内容和口播语义选择。你明确指定的风格优先于默认设置。

## 工作方式

| 阶段 | 交付内容 | 用来确认什么 |
| --- | --- | --- |
| 理解口播与参考 | 观点、依据、逻辑关系；必要的参考拆解 | 画面需要解释什么 |
| 整理素材 | 素材清单、来源与缺口 | 证据和画面是否匹配 |
| 静态分镜 | 代表页、分镜缩略图、手机比例合成图 | 设计、素材类型和信息量 |
| 短样片 | 代表性的 10–15 秒片段 | 阅读节奏、音画配合与分屏 |
| 全片与验收 | 沿用确认规则的成片及检查结果 | 完整播放、字幕、裁切与同步 |

可以只完成其中一个阶段。已确认的风格和选择会继续沿用。

## 能力与依赖

本 Skill 包含制作规范、分镜模板、视觉参考和验收清单。它不自带视频渲染引擎。

- 提供脚本时，可开展观点整理和分镜设计；有可用设计工具时可制作实际页面。
- 完整参考视频拆解需要能读取视频、检查音轨并获取转写的工具。
- 全片制作需要可用的素材、视频合成工具与相应运行环境。
- 缺少工具或素材时，Agent 会说明具体缺口，并完成当前可执行的阶段。

**Hypit 为可选工具。** 参考拆解模块借鉴其参考视频阅读与组件设计方法；当前版本尚未集成 Hypit Runtime。具体执行能力以实际安装和环境检查为准。
