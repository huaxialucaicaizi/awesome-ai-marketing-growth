# 制作流程

## 通用流程

理解口播观点与依据 → 整理现有素材 → 区分已确认与待补 → 建立 A-roll/B-roll 语义映射 → 补素材 → 静态分镜确认 → 短样片 → 全片 → 验收。

普通 AI 产品热点使用对应的真实界面、演示或操作结果；竞品关系与作者判断使用自制解释页或策略页；涉及具体发布会时才使用对应现场照片与 Keynote。

使用随包提供的视觉参考，不依赖临时路径或内部文件 ID。不要声称已使用未经核实的制作软件或运行能力。

## 每个项目保留的工作记录

- 当前视频版本与实际总时长。
- 原口播文本及句子切点。
- 视觉参考、已确认样张及用户修改记录。
- 素材表：编号、类型、主题、来源、截取位置、审核状态。
- 分镜表：口播区间、主画面、唯一观点、停留时间、切点。
- 验收状态与待补素材。

不将内部路径、暂存编号、校验过程或缺素材备注叠进正式画面。
