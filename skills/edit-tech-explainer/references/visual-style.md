# 视觉规范

先打开 assets/deepseek-style-reference.png；文字规范不能代替看参考图。

## 已有参考中的视觉语言

主体页面为白/浅灰背景、蓝紫渐变强调、深色无衬线文字、柔和阴影、蓝色关系连线及立体模块。机器人、积木、模块和图表均用于解释概念。参考中的黄色时间码是分镜审核标记，不是正式视频必须包含的装饰。结尾深色页是局部用法，不代表主体页都用黑底。

## 可复用的设计起点

以下数值是为复用补充的建议，不声称是旧视频精确测量值：

- 背景：#F7F9FC 或白色，渐变可用 #EDF3FF 到 #F1EDFF。
- 正文：#172033；强调：#3B67F2；辅助强调：#7D63D7。
- 字体：清晰的中文无衬线与匹配的英文无衬线。上方约 1080px 宽的画面，主题约 64–88px，Logo 名约 32–44px；根据实际手机预览调整。
- 留白：Logo 周围留足空间，三项视觉面积相近，沿一条基线排列。不要用大小相同的外框强行补偿 Logo 不同形状。
- 立体感：仅让必要的对象具有浅阴影、半透明材质或柔和光感；文字和品牌 Logo 保持清晰。

## 同赛道产品比较页

主题使用本片比较的赛道。对应产品的原始品牌 Logo 和名称放在同一横排；维持同一页，不为每个品牌切图。可以按口播轻微强调当前对象，不反复闪动。使用浅色蓝紫科技风作为默认；不要加解释段落、功能清单、无关机器人或另一个策略结论。

用户要求与一场发布会完全一致时，先取得真实官方 Keynote 参考，提取背景、字号、配色与留白；不能只凭“官方通常极简”猜测。在没有原图时清楚标记为试稿，优先沿用本 skill 的已知风格。
