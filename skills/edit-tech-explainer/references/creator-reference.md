# 拆解与模仿博主视频

当用户给出博主、视频链接、参考片或“模仿这种风格”时，按本流程工作。若只给博主名称，先定位准确账号与代表视频；同名或风格差异会影响结果时请用户指定。只有截图时先分析静态视觉，不能声称已知道整片节奏、声音或转场。

## 获取可检查的证据

1. 保存可合法获取的参考片、原链接与版本。链接受限时记录缺口，使用用户提供的文件继续可完成的工作；不要绕过访问限制。
2. 检查实际时长、尺寸、帧率、音轨和字幕。使用当前工具提取转写与时间码，并核对专名。Hypit 可用时按其当前文档使用 transcribe、media frames／tiles／boundaries；否则用可用转写工具、ffprobe、ffmpeg 与图像拼图完成同类检查。
3. 通看并听完整参考，再围绕重要段落、画面变化与难以辨认的细节抽帧。粗略采样不能代替对关键变化的检查。无法访问声音或完整片段时标明未核验范围。
4. 保存带时间码、口播短语的联系表和代表帧。对转场查变化前、变化中、变化后；对复杂页面放大查字号、信息层级与空间关系。

## 拆解六个维度

| 维度 | 需要记录的具体证据 |
| --- | --- |
| 内容结构 | 开头怎样提出问题、论点如何推进、证据如何出现、结尾如何兑现开头 |
| 口播与画面 | 哪一句触发切镜、高亮、图表、UI 或回到人像；为什么有帮助 |
| 视觉系统 | A/B-roll 比例、留白、字号、配色、Logo、图示、字幕安全区与层级 |
| 阅读与剪辑节奏 | 每页实际停留、信息增量、同页变化、停顿与转场；避免仅统计切镜次数 |
| 动态与声音 | 元素的进入、持续、变化与退出，音乐和音效如何配合语义 |
| 人物表达 | 语气、语速、停顿与手势怎样组织注意力；保留新视频作者本人的表达 |

记录表至少包含：时间区间、口播短语、观察到的画面／声音、出现与退出、持续对象、视觉作用、解释置信度、可迁移规则。把观察和“我认为这有助于…”的解释分开，不声称从视频还原了作者源码或制作软件。

## 输出可迁移的模仿方案

先交付三样内容：

- 参考拆解表与代表帧：每个规则都有视频证据。
- 风格说明：字体、配色、空间层级、B-roll 类型、阅读节奏、转场规则与可复用组件。
- 适配表：参考的表达规律 → 本片对应的判断／口播 → 新素材与画面 → 保留或调整的理由。

将参考的机制用于新选题：可以迁移“观点出现时展示对照”“关系图持续到完整解释结束”等规律，不能机械复用相同秒数或每句话都切镜。默认沿用本 skill 的浅色科技风；本次明确指定模仿另一视觉体系时，以本次要求为准，并先提交静态对照样张。多参考组合时说明分别借鉴了谁的结构、视觉或节奏。

使用新视频作者的观点、事实、原声、人物和已核实素材。不要将参考的台词、项目专名、案例结论、品牌身份或博主人像当成本片默认内容。未获授权的参考素材仅用于分析，不自动嵌入公开成片。用户另有明确素材授权时按授权范围使用。

先用一张真实内容的静态图和一个代表段落检验：它是否保留了参考的表达规律，同时让本片的观点更清楚。通过确认后再扩展全片；不承诺复刻参考视频的播放量或增长结果。

## 与 Hypit 的关系

本模块借鉴 Hypit 的参考阅读、语义组织和组件设计方法，并以可用工具执行。增加此文档不代表已经安装 Hypit、配置 Runtime 或实现其完整渲染功能。

仅在用户需要实际 Hypit 执行、可编辑时间线或 Studio 评论时，检查 executable、Skill、服务配置和当前文档。将安装、模型账户与付费服务分别处理；遵循当前环境的授权规则。不可用时明确限制，仍完成不依赖它的参考分析与静态分镜。
