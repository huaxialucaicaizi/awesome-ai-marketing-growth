# 交付前检查

## 视觉与内容

- 与 bundled DeepSeek 参考并排检查：浅色底、蓝紫强调、立体科技语言是否一致。
- 在实际竖屏、手机可读尺寸检查，不能只检查横版单页。
- 画面是否解释当前完整口播语义；宣布新品是否使用对应现场＋Keynote。
- Logo、产品名、模型名与事实是否来自原始来源；跨层级竞品比较是否明确为作者解读。
- 一页一个观点；无重复标题、来源长文、能力标签与竞品清单同时堆叠。
- 每页是否能在停留期间看清；短样片是否过密换页。
- A-roll 全程存在，脸部、手势、麦克风与中英字幕未被不当裁切，原声连续。
- 进度条仅在用户要求时出现，位于分界处，不压住字幕。

- 策略页是否表达了有依据的关系，还是只罗列关键词；是否能说明这张图如何支持作者判断。
- 模仿参考时是否有时间码与代表帧证据，内容结构、视觉和节奏是否已适配新口播；未检验的声音或片段是否明确标注。
- 原声改变后是否重测语义切点；是否保留了新作者的声音、人物、观点和来源，而未混入参考片的专属事实。

## 导出完整性

1. 编码到临时路径，等待进程成功退出。执行环境若会在后台任务结束后才同步文件，应在同一次命令里等待完整渲染并检查，勿在初次 yield 时上传文件。
2. 使用 ffprobe 检查目标文件有视频、所需音频、有效 duration、尺寸与帧率；核对预期片段时长。
3. 使用 ffmpeg -v error -i VIDEO -f null - 完整解码。退出码非零时修复后重新检查，不继续保存为成品。
4. 抽查开头、切点、结尾的实际导出帧。确认没有黑帧、错误 Logo、画面遮挡与跨段音画错位。
5. 检查成功后再将文件移至最终路径并保存。不要把尚在写入、缺 moov atom、尚未完整解码的视频当作成品。

不要将“工具返回成功”“命令打印 encode 0”或“图片尺寸正确”视为完整验收。
