# AI 热点口播视频 · Tech Explainer

围绕当前 AI 热点的产品、功能、概念或趋势，先理解作者口播的观点和依据，再设计解释画面。热点事实以本次核实的来源为准，区分实际能力、宣传信息和作者判断。复用已确认的视觉与工作流程，将用户本次明确要求置于所有默认设置之上。

## 开始前

1. 打开并目视检查 [DeepSeek 风格参考](assets/deepseek-style-reference.png)。读取 [视觉规范](references/visual-style.md) 和 [制作流程](references/workflow.md)。
2. 读取当前口播视频、字幕或脚本及已确认分镜。按 [视觉论证](references/visual-argument.md) 提炼每段的判断、依据、关系与观众应记住的结论；未参与写稿时也先还原这些逻辑，再排版。沿用当前项目决定，不将旧视频的事实、模型名称或时间轴带入新片。
3. 明确当前交付阶段：风格对齐、分镜审核、短样片或全片。用户只要求一个阶段时，完成该阶段，勿擅自跳到全片渲染。
4. 使用实际可用的图像、视频、演示页面或剪辑能力。旧记录未明确制作软件与具体 skill，不声称上次使用过某工具。

## 博主参考与风格模仿

用户要求拆解或模仿博主时，读取 [参考视频分析与适配](references/creator-reference.md)。检查完整视频与关键变化，交付有时间码证据的拆解表、风格说明和本片适配表。先理解每种表达如何服务观点，再用本片自己的口播、人物与事实实现。Hypit 为可选执行工具；不要把借鉴其方法说成已经接入它的运行能力。

## 固定视觉方向

- 使用白色或浅灰底、淡蓝紫渐变、深色标题、蓝紫重点。通过立体模块、柔和光影与表达关系的图形产生科技感。
- 使用 [视觉论证](references/visual-argument.md) 中的关系选择图形。策略页必须使比较、因果或生态关系可见；不能把减少信息量简化为几个孤立关键词或通用卡片。用户明确要求的纯 Logo 页保持简洁。
- 保持版式简洁。不要把“科技风”简化成纯黑底加白字，也不要用霓虹网格、代码雨、泛化科技素材代替内容。
- 延续参考的视觉语言，不机械复制所有机器人、积木、彩色卡片或装饰。竞品页可以只有主题和 Logo。
- 使用原始品牌 Logo，保持形状与比例，优先品牌原色。需要单色版本时使用品牌允许的对应资源，不随意改造。
- 分析页呈现作者解读；官方现场与 Keynote 保留真实内容。不要让自制分析页看起来是官方发布原图。

## 根据口播选画面

| 口播目的 | 主画面 | 执行要求 |
| --- | --- | --- |
| 介绍 AI 产品、功能更新或实际能力 | 真实产品界面、官方演示或操作结果 | 根据当前口播核对产品版本与实际能力，匹配具体功能；不把宣传效果当成已验证结果 |
| 解释 AI 概念、热点趋势或能力差异 | 自制解释页、对照页或关系图 | 从脚本提炼关系和比较维度，区分事实与作者分析；素材需支持当前判断 |
| 宣布、介绍发布会上的产品或更新 | 发布会现场照片/直播截帧＋对应官方 Keynote | 先检索该场发布会的对应素材。照片与 Keynote 可合成一张持续展示；不要自动换成产品宣传动画或操作视频 |
| 讲竞品、赛道、战略、产品之间的关系 | 自制策略页面 | 一页一个主题。比较同赛道产品时，展示主题及对应竞品 Logo，同屏持续停留 |
| 讲具体功能、操作步骤或任务结果 | 真实产品界面/录屏 | 对准口播提到的区域，展示输入、操作或结果；不伪造功能，不用无关 UI 充当证据 |
| 总览或目录 | 同风格目录/总览页 | 内容随口播轻微高亮，保留页面，不逐词切新页 |

素材缺失时记录缺口，使用已核实且能支持同一判断的同类素材替代；无法获取时明确说明。发布会现场与 Keynote 仅在本次口播确实涉及该发布会时使用，不作为普通 AI 产品热点的默认画面。

## 制作顺序

0. **口播理解与参考拆解**：明确观众、作者判断、依据和逻辑关系；有博主参考时先提炼可迁移规则。为关键画面变化记录触发短语，复用组件时保留关系而非固定秒数。
1. **素材资产库**：整理产品界面、官方演示、实际操作结果、解释图及本片需要的其他素材，标记已确认/待补充及来源。
2. **口播映射**：按完整语义句划分时间段，填写 [分镜表](references/storyboard-template.md)。一个画面可覆盖多句，勿按每个名词或字幕行切画面。
3. **静态分镜**：新视觉尚未确认时，先做一张有实际文字和 Logo 的策略页样张；再展示分镜缩略图及对应口播。使用原 A-roll 合成手机比例检查图。
4. **短样片**：视觉与素材类型已确认后，制作具有代表性的 10–15 秒样片，检查节奏与上下分屏。不要反复用样片试探尚未对齐的静态设计。
5. **全片**：沿用确认过的资产及样片规则，只补缺口，不偷偷改变视觉或剪辑逻辑。
6. **交付检查**：执行 [验收清单](references/quality-check.md)，检查视频容器与完整解码后，保存并交付。

用户要求“先确认”时，提交具体样张或分镜供其选择，不进入后续渲染。已确认的选择无需反复询问；明确授权完整制作时，在已确认风格内继续执行。

## 构图与节奏

- 默认 9:16，上方 B-roll、下方 A-roll；A-roll 全程可见，原声连续，字幕可读。保留开头原 A-roll 构图，目录起进入上下分屏，除非本次指定其他开场。
- 将上方约 58%、下方约 42% 作为起点，按源视频比例、头顶与字幕安全区调整，不裁掉人像或字幕，不拉伸。
- 一页一个观点。主题＋最多三个 Logo/模块通常足够。不要同时堆大标题、界面、来源说明、能力标签、竞品名单和策略结论。
- 根据阅读量决定停留时间：简洁 Logo 页通常 6–8 秒，关系图通常 8–12 秒。以口播语义切点为准，不能为了凑秒数提前引入下个产品或截断语音。
- 同页高亮或局部慢放大优先于换页。观众尚未读完时不切走。不要每提一个竞品就换一张图。
- 用户要求进度条时，放在上下分界处，使用细线＋当前章节名，按全片时间推进；不显示完整三章节导航、百分比或抢眼装饰。
- 复杂图的圆形人像窗口只在用户明确选择后使用；默认保留上下分屏。

## 工具与持久化

按任务使用可用的 Presentations、图像生成、素材检索及视频合成工具，不强制依赖未安装的工具。指定 skill 不可用时先检索并说明，不冒称使用。

生成精确文字、品牌 Logo 和流程关系时，优先原始资源与可编辑布局。AI 图像生成适合参考风格的立体插图，不用于捏造官方界面、Logo、发布会照片或精确事实。

将用户交付物按当前环境的文件保存规则持久保存；参考素材和项目资源不要依赖会过期的临时路径或签名 URL。编写文件到临时输出，等待编码成功且检查通过后再原子移动到交付路径。没有通过检查的文件不得上传成品。
